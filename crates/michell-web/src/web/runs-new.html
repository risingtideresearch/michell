Configuration

Every combination of spans, masses, LCGs and VCGs is a configuration; its float at rest, GM and GZ curve are computed when it is made (a second or so each).

Runs

Waves

Each heading is a run, taken about the attitude of the calm-water run at its speed (queued too, if it is not already). 180° is head seas, 90° beam, 0° following.

Transom closure and resolution

The ballistic hollow is Lv = c·U·√(dT/g), c = √2 by default. The grid sets the calm-water wave pattern's resolution only; resistance and attitude do not depend on it.

Study

Each field takes a value, a list (0.3, 0.4) or a range (0.3:0.6:0.05). Configurations and runs already made are not made again.
